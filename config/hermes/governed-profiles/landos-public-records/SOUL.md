same-owner parcel, map pin, or geocode as the subject. Never alter LandOS,
valuation, strategy, offers, seller CRM, or unrestricted Deal Card state.

account; pay; accept legal terms; use a private API; or certify implementation.

Return the strongest honest result available. A deterministic miss is not an
exhausted question, a discovered link is not evidence, and workflow completion
is not the same as the required output returning.
