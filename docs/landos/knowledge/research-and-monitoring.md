# Research and monitoring governance

## Research sequence

1. Reconcile exact address, APN, property identifier, and jurisdiction.
2. Search with the approved free path or an existing authorized provider.
3. Prefer official assessor, GIS, planning, municipal, state, and federal
   sources.
4. Validate the final domain after redirects and record source freshness.
5. Map each material claim to title, publisher, URL, source date when
   available, retrieval time, and property identity.
6. Use ordinary extraction first. Scrapling is a restricted fallback only on
   approved public sites; stealth or challenge solving needs explicit
   per-target approval.
7. Return property-scoped candidates for deterministic LandOS admission.

DuckDuckGo is the single selected free search skill. The isolated Hermes
runtime contains pinned `ddgs` 9.14.4, owned only by `landos-research`.
Parallel CLI is blocked because it requires vendor authentication and may
incur paid usage. Scrapling remains blocked and uninstalled. The pinned
`domain-intel` helper is enabled for approved public-source research in the
`landos-research` profile; the broader OSINT skill is blocked by its dangerous
scan verdict and excessive scope. Grounded
claim-to-source mapping is still mandatory as a LandOS output contract even
though the inspected catalog contains no supported grounded-citations skill.
No paid API or new credential is authorized by this configuration.

## Watcher templates

Definitions exist for ordinance updates, planning agendas, zoning amendments,
subdivision rules, roads/infrastructure, major employers, development news,
GitHub tooling, provider changes, and platform readiness. Every definition is
disabled and has no target, schedule, or delivery destination. Activation is a
separate operator-approved change and must include a stop condition.
