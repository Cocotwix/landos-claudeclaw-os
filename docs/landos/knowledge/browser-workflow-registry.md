# Browser workflow registry

## LandPortal exact-subject specialists

Use only the already approved authenticated endpoint and one tab owned by the
assigned specialist. Subject, comps, and visuals independently prove the same
address, APN, subject URL, and LandPortal property identifier. Only the visuals
specialist drives map framing or overlays. Handbacks do not mutate a Deal Card;
the LandOS importer owns admission.

## County and municipal public records

Recognize the platform, load the known adapter, apply jurisdiction
configuration, run deterministic selectors, and escalate to a bounded browser
workflow only when necessary. Persist safe selectors, source metadata,
limitations, and recovery steps without credentials, cookies, or private
session data.

## Visual acceptance

Every run creates a new isolated Playwright context, uses only approved
authentication state, records trace/video/screenshots/console/network/results,
and closes all pages and contexts. User-visible roles and labels are preferred
over implementation selectors. Refresh and managed-restart inspection are
parts of the same full run; a failed assertion is never rerun alone as proof.

The machine-readable registry is
`config/landos-knowledge/registries/browser-workflow-registry.json`.
